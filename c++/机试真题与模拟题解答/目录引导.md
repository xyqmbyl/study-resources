## 2020 之后：PIPIOJ 历年公开赛（中南大学机试方向）

> 中南大学机试在 **PIPIOJ**（[pipioj.online](http://pipioj.online)）上进行——该 OJ 由「PIPI考研」社区运营（中南大学计算机考研群 546311977），是中南考研机试的官方练习平台。
> **性质说明**：2020–2025 公开赛是 PIPIOJ 每年 1 月举办的年度赛，由中南考研社区的学长出题，赛制与难度对标考研复试机试（4 小时 5-6 题），被广泛当作机试真题练习，但**并非考场原题**；其中 2023 模拟机试周赛页面明确标注"全程模拟机试赛，祝大家复试上岸"。严格意义上确认的历年考场真题是 2013–2019 这部分。
> **2020–2025 全部 7 场比赛共 36 道题的题面均已保存到本地**（Markdown 文件，含题目描述/输入/输出/样例/提示，数学公式已还原为 LaTeX），无需联网即可阅读。

## 注意事项（摘自原 README）

1. **输出格式**：多组输出时，有的题目要求一一及时输出，而不是最后统一输出（见 2014 破译密码1）。
2. **精度与溢出**：注意 `float` 与 `double` 的精度差异，以及整数溢出导致的答案错误。
3. **memset 陷阱**：`memset()` 按字节赋值，对非字符类型初始化要用 `<algorithm>` 的 `fill()`：

   ```cpp
   int a[10];
   memset(a, 0, sizeof(a));   // ✅ 全 0
   memset(a, 127, sizeof(a)); // 约为 2139062143，常用于「无穷大」
   memset(a, 1, sizeof(a));   // ❌ 得到 0x01010101 = 16843009
   ```
