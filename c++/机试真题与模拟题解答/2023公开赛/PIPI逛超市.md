# 问题 B: PIPI逛超市

- 来源：PIPIOJ 2023 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1054&pid=1)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PIPI家镇上有一家超市，有一天PIPI想去超市买n样东西，这n样东西在超市都是m元，但是老板说最近有促销活动，如果你买了第i样东西，那么再买第j样时就可以只花Kij元。
现在PIPI想知道，他购买这n样东西最少要花多少钱。

## 输入

第一行两个正整数m和n。m<=1000,n<=500
接下来输入一个n*n的矩阵K，Kij(不超过1000)代表已经买了第i样商品后，就可以用Kij的价格来买第j样商品。
Kij=0代表买了第i样商品后，买第j样商品无优惠，保证Kij=Kji。

## 输出

输出所花费的最少钱数。

## 样例输入

```text
5 3
0 3 2
3 0 4
2 4 0
```

## 样例输出

```text
10
```
