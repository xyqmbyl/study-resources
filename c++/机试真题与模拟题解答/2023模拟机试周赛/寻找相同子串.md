# 问题 D: 寻找相同子串

- 来源：PIPIOJ 2023 模拟机试周赛（[题目链接](http://pipioj.online/problem.php?cid=1055&pid=3)）
- 时间限制：1s　内存限制：128MB

## 题目描述

有n个长度为L的字符串，你的目标是寻找出所有长度为k的字符串，且至少是m个所给字符串的子串。
输出满足题意的子串数量。

## 输入

多组输入。
第一行四个整数n,m,k,L(1<=m<=n<=100,1<=k<=L<=3000)。
接下来输入n个只包含大写字母的字符串。

## 输出

输出至少存在于m个字符串，且长度等于k的子串数量。

## 提示

满足题意的子串为AB,BC

## 样例输入

```text
3 2 2 3
ABC
ABD
BCA
```

## 样例输出

```text
2
```
