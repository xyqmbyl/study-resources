# 问题 C: 反对称矩阵

- 来源：PIPIOJ 2024 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1056&pid=2)）
- 时间限制：1s　内存限制：128MB

## 题目描述

反对称矩阵是指方阵A对于任意的i≠j，满足Aij不等于Aji。
现在有一个n*n的01方阵，其中还有一些空没有填，现在要求你使用0或1补全该方阵，问是否能使它成为反对称矩阵。
如果可以变为反对称矩阵，把矩阵的每行连接成一行，输出字典序最大的那个字符串，否则输出impossible。

## 输入

多组输入。
第一行输入矩阵的大小n（1<=n<=200）。
接下来输入一个只包含-或0或1的n*n的矩阵，
-代表为空，0和1代表已经填了的数。

## 输出

输出由填完矩阵得到的字典序最大的字符串。
如果填不出符合要求的矩阵，输出impossible。

## 提示

第一个用例得到的矩阵为

```
110
010
111
```

## 样例输入

```text
3
1-0
--0
-1-
2
-0
0-
```

## 样例输出

```text
110010111
impossible
```
