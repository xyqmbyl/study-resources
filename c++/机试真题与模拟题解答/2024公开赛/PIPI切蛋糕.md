# 问题 B: PIPI切蛋糕

- 来源：PIPIOJ 2024 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1056&pid=1)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PIPI今天过生日，他买了一个圆形的蛋糕，但是他觉得圆形不好看，PIPI喜欢正k边形，所以他想切一个最大的正k边形蛋糕。经过测量，这个蛋糕的半径为r，那么PIPI切完后的蛋糕面积有多大呢？
tips: 为了保证精度，π = arccos(-1)。

## 输入

输入包含多组测试用例。
对于每一组测试用例，输入两个正整数 r, k,代表圆的半径r以及多边形的边数 k。 (0<r≤100000，3≤k≤100)

## 输出

对于每组测试用例，请输出切完之后蛋糕的面积 S ， 答案保留 3 位小数。

## 样例输入

```text
20 3
```

## 样例输出

```text
519.615
```
