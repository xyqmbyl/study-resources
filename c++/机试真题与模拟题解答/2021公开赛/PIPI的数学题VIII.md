# 问题 A: PIPI的数学题VIII

- 来源：PIPIOJ 2021 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1022&pid=0)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PIPI想知道半径为 r 的圆内内接正多边形面积是多少，你能帮PIPI解决这个问题吗？ 
tips: 为了保证精度，π = arccos(-1)。

## 输入

输入包含多组测试用例。 
对于每一组测试用例，输入两个正整数 r, k,代表圆的半径r以及多边形的边数 k。 (0<r≤10000，3≤k≤100)

## 输出

对于每组测试用例，请输出内接正多边形面积 S ， 答案保留 3 位小数。

## 样例输入

```text
20 3
```

## 样例输出

```text
519.615
```
