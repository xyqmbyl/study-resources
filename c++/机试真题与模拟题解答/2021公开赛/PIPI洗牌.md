# 问题 E: PIPI洗牌

- 来源：PIPIOJ 2021 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1022&pid=4)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PIPI有n张牌，每张牌面上都有相应的权值，现在它想玩一个游戏:
你可以把n张牌以任意顺序打乱，然后从左至右摆放，分别编号为1~n，它想知道对于每张牌与其右边第k张牌(如果存在)差值的绝对值的和最小是多少？
简单来说，你可以把洗好的牌看成一个数组，使得下式最小（原题为公式图，即 $\sum_{i=1}^{n-k} |a_i - a_{i+k}|$）。

## 输入

单组数据。 
第一行给出两个整数n和k，n<=5e5，k<=min(5000,n-1) 
接下来给出n个整数ai，表示n张牌上的权值，|ai|<=1e9

## 输出

输出满足题目要求的最小值。

## 样例输入

```text
3 2
1 2 4
```

## 样例输出

```text
1
```
