# 问题 D: 魔术师PIPIⅡ

- 来源：PIPIOJ 2021 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1022&pid=3)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PIPI作为当代最强的魔术师，曾有名言："May the magic be with you!"，而POPO今天则想请这位大魔术师来实现她的愿望。
POPO会给PIPI一个数字a，但是POPO希望PIPI能使用魔术把他变成另一个数字b。POPO保证a和b的数位相同且a和b为4位素数或者5位素数。
PIPI虽然魔力滔天但他的能力还是有所限制，他每次使用魔术只能将a其中的一位数字改成另一位数字，且改完后得到的a必须仍然是素数。
请问PIPI最少使用多少次魔术能将a变成b。

## 输入

第一行一个正整数T表示数据组数，T<=20。 
接下来T行，每行两个四位素数或者五位素数a和b。

## 输出

对于每组数据，输出PIPI最少使用的魔术次数。若PIPI无法将a变成b，输出-1。

## 样例输入

```text
1
1033 1033
```

## 样例输出

```text
0
```
