# 问题 C: PIPI的炸弹

- 来源：PIPIOJ 2020 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1012&pid=2)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PIPI和POPO吵的不可开交，甚至于他们决定玩一个炸弹游戏，从而彻底消灭对方。
游戏开始时PIPI拿着一个炸弹，其在x秒之后会爆炸，爆炸时拿着炸弹的人将被炸死，而另一方则成功存活下来。为了增加游戏的乐趣，PIPI和POPO在拿着炸弹时，可以将炸弹的时间调快y(a<=y<=b)秒，调快无需消耗任何时间，当然他们也可以选择不将炸弹调快。同时他们会将炸弹交给对方，每次交换将消耗1秒。
假设PIPI和POPO都足够聪明的前提下，谁会活下去呢？

## 输入

第一行有三个整数x,a,b，分别表示炸弹初始时刻的倒计时，可调节时间的范围。(0 ≤ x ≤ 10^6,1 ≤ a ≤ b ≤ 10)

## 输出

若PIPI存活则输出"PIPI"，若POPO存活则输出"POPO"。

## 样例输入

```text
6 3 4
```

## 样例输出

```text
PIPI
```
