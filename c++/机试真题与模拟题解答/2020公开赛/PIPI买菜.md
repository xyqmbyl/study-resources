# 问题 E: PIPI买菜

- 来源：PIPIOJ 2020 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1012&pid=4)）
- 时间限制：1s　内存限制：128MB

## 题目描述

有一天PIPI去菜市场买菜，捡到了一个菜篮子，篮子里面装着从L~R的R-L+1个正整数，现在它不想买菜了，想玩一个游戏：
它想从这R-L+1个正整数里面选出不超过K个整数，使得选出的整数异或和要尽可能小。
PIPI不需要你给出选出数字的方案，只要输出最小的异或和就行了。

## 输入

单组输入。 
第一行给出三个正整数L,R,K，其中L,R<=1e12,K<=R-L+1.

## 输出

输出一个正整数表示答案。

## 样例输入

```text
8 15 3
```

## 样例输出

```text
1
```
