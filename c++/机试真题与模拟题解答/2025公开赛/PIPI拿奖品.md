# 问题 A: PIPI拿奖品

- 来源：PIPIOJ 2025 公开赛（[题目链接](http://pipioj.online/problem.php?cid=1068&pid=0)）
- 时间限制：1s　内存限制：128MB

## 题目描述

PiPi参加活动中了大奖！！！ 
现在他可以从一排奖品中拿走一些奖品，但是PiPi只能拿走连续的奖品。 
已知每个奖品都有一定的价值，而PiPi在心里也有一个目标 target 。 
你能帮PiPi找出这一排奖品中满足其价值总和大于等于 target 的数量最小的奖品个数吗。如果不存在符合条件的连续奖品，返回 0 。

## 输入

多组输入 
对于每组输入，第一行有一个正整数n表示奖品的数量 
第二行有一个正整数target，表示PiPi心里的目标值 
第三行有n个正整数，表示n个奖品的价值 
1<=n<=1e5 
1<=target<=1e9 
1<=奖品的价值<=1e4

## 输出

每组输入输出一个正整数，表示数量最少的奖品个数 
如果不满足要求，则输出0

## 样例输入

```text
6
7
2 3 1 2 4 3
```

## 样例输出

```text
2
```
