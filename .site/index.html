管理台

用 GitHub Token 登录：有仓库写权限（协作者）→ 管理员模式，可直接上传、替换、移动、删除资料；无写权限（普通同学）→ 投稿模式，同样能上传资料，系统自动 Fork + 提 PR，管理员合并后上线。Token 只保存在你自己的浏览器里。

❓ 没有 Token？点开三步获取教程（普通同学投稿同样需要）
  1. 打开 github.com/settings/personal-access-tokens/new（需先登录 GitHub）
  2. Token name 随意填；Repository access 选 All repositories（普通同学投稿需要访问你自己账号下的 Fork，不能只选本仓库）
  3. Permissions → Repository permissions → Contents 设为 Read and write，其余不用动 → Generate token
  4. 复制生成的 token（github_pat_ 开头）粘贴到上面输入框

没有 GitHub 账号或不想折腾？看 贡献指南：直接 开 Issue 求资源也行。

📖 使用说明

🔍 怎么搜

点顶部搜索框（快捷键 Ctrl K）输入关键词，按文件名 / 科目 / 关键词全文检索。中文自动拆词，「高数」「线代」「电分」等缩写也能直达对应科目；没有精确命中时会自动模糊兜底。搜索框下方可按类型筛选：文件 / 视频课程 / 电子书。

🗂 怎么浏览

左侧目录树按科目逐层点开浏览；顶部「☰ 自定义导航」可拖动调整科目顺序、取消勾选隐藏不关心的科目（设置只保存在你自己的浏览器里，随时可恢复默认）。

👁 怎么在线预览

点资料卡的「在线预览」即可直接阅读：PDF / 图片 / 代码文本由浏览器原生渲染，Word / PPT 自动转换预览。Safari 与微信内置浏览器同样可用（自动走 pdf.js 兜底，支持翻页、缩放）。超过 20MB 的大 PDF 会先经代理下载到本地再打开，首次加载稍慢属正常。

⬇ 怎么下载

点「下载」会自动选择当前最快的线路（jsDelivr CDN → GitHub → 加速代理，失败自动降级，无需手动选）；超过 100MB 的大文件自动指向 Releases 附件通道，速度慢请耐心等待。

🌙 个性化

右上角 🌙 切换深浅色、🖼️ 换壁纸，偏好自动记住，下次访问保持不变。

📱 手机端

左上角 ☰ 打开目录抽屉，点资料卡即可预览、点「下载」即可保存，体验与电脑端一致。

🤝 想投稿 / 没找到想要的资料？

页脚「管理台」用 GitHub Token 登录即可上传投稿（自动 Fork + 提 PR，Token 获取教程内嵌在登录框里）；没有 GitHub 账号也没关系，直接 开 Issue 求资源 / 反馈 就行。
