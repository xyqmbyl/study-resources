# 中南大学学习资源共享站

21 个科目的真题、笔记、PPT、电子书与视频链接资源。

- **网站**：https://xyqmbyl.github.io/study-resources/ （检索 + 在线预览 + 多线路下载）
- **下载通道**：jsDelivr CDN → raw.githubusercontent → 加速代理，自动降级
- **超 100MB 大文件**：见 [Releases](https://github.com/xyqmbyl/study-resources/releases)
- **更新资源**：直接 push 到 main 即可，Actions 会自动重建索引并部署网站；或在网站管理页（`/#admin`）用 Token 上传
