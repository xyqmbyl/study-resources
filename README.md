- 🌙 深浅色主题、自定义壁纸、手机端适配

## 📮 如何贡献

欢迎共建！按你的情况选一条路线即可：

| 你的情况 | 推荐路线 | 需要会什么 |
|---|---|---|
| 任何人有 GitHub 账号，想传资料 | **路线 A：网站管理台投稿** | 会用浏览器即可，零命令行 |
| 想找资料 / 连 GitHub 都不想折腾 | **路线 C：开 Issue** | 只需会填表单 |
| 有仓库写权限（协作者 / 管理员） | **路线 A：网站管理台** | 会用浏览器即可 |
| 熟悉 git | **路线 D：git push** | 基础 git |

### 路线 A · 网站管理台（普通同学投稿 / 协作者管理，推荐）

1. 打开[网站](https://xyqmbyl.github.io/study-resources/) → 页脚「**管理台**」→ 粘贴 GitHub Token 登录（Token 创建教程已内嵌在登录框里；**普通同学投稿也用它**，无需管理员授予仓库权限）
2. 两种模式自动识别：
   - **有仓库写权限（协作者）**：三个标签页——**📁 文件管理**（浏览 / 替换 / 移动改名 / 删除，含 Release 大文件管理）、**⬆ 上传**（拖拽上传、可整文件夹、自动检测同名冲突）、**➕ 新建文件夹**；单 commit 直推仓库
   - **无写权限（普通同学）**：进入「**⬆ 投稿**」标签上传即可——系统会自动 Fork 本仓库到你的账号、提交文件并**自动创建 PR**（PR 链接会显示在日志里），管理员合并后约 1 分钟建索引、网站即可搜到
3. 多个文件会打包成**一次 commit** 提交；投稿后 PR 保持 Open 期间如有补充，向你的 Fork 同一分支继续 commit 会自动并入

### 路线 B · Fork + 网页上传（不开 Token 的小白替代方案）

1. 点右上角 **Fork** 把本仓库复制到自己账号下
2. 进入自己 Fork 的仓库 → **Add file → Upload files** → 把文件**拖进去**（上传时记得选对科目文件夹，也可新建子文件夹；「资料存放位置」写在 commit 说明里更好，如 `高数/2026真题/`）
3. 底部 Commit changes → 点 **Contribute → Open pull request** 提交 PR
4. 等待合并即可。**PR 保持 Open 期间如有补充资料，直接继续向同一分支上传 commit，会自动并入这个 PR，不用另开**

### 路线 C · 开 Issue（不动手也行）

不想折腾 git 或网页操作？点 [Issues → New issue](https://github.com/xyqmbyl/study-resources/issues/new/choose) 选表单：

- **📥 求资源 / 补充资料**：选科目、写资料名、贴链接，管理员看到会帮忙上传
- **🐛 报告问题**：下载失效、文件有误、网站异常

### 路线 D · git push（熟手）

把文件放进对应科目文件夹（新建科目就新建文件夹），push 到 `main` 即可；Actions 会自动重建索引并部署。多人协作请先 `git pull --rebase`。

### 📏 文件大小分档

| 大小 | 怎么传 |
|---|---|
| ≤ 100MB | 直接走上面任意路线（网页上传 / git 均可） |
| > 100MB | **不要 push 进仓库**。放网盘后开 Issue 贴链接，或联系管理员放入 [Releases](https://github.com/xyqmbyl/study-resources/releases) 附件通道 |

### ⚠️ 版权红线（每位贡献者须知）

- 只上传**自己有权分享**的学习资料（自己拍的笔记、老师明确允许传播的课件、官方公开的历年真题等）
- **严禁**上传商用盗版资源（付费网课录屏、盗版商用软件、盗版付费题库等）
- 拿不准就先开 Issue 问，避免给仓库带来风险
